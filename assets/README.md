# Repository artwork

`preview.png` is the repository cover, embedded at the top of README.md. Keep the relative path when uploading the project to GitHub. It can also be uploaded manually as a repository social preview; check GitHub's crop preview before saving.

The illustration uses the MOHAPX-V-IT portfolio palette: charcoal, warm orange, off-white and geometric typography. Generated with the built-in image generation tool. Exact generation prompts are in `prompts.txt`.
